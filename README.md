# Интеллектуальная система управления БПЛА и анализа NDVI (7-этапное веб-приложение)

Веб-приложение разработано по теме **«Проектирование интеллектуальных систем управления»** и реализует полную 7-этапную архитектуру управления беспилотным летательным аппаратом (БПЛА) для агромониторинга полей Казахстана (Акмолинская и Алматинская области).

## Структура системы (7 этапов)

Каждому этапу соответствует отдельная интерактивная веб-страница с последовательными переходами по кнопке:

1. **[Главная / Архитектура](index.html)** — Интерактивная структурная схема (Рисунок 1), описание процесса сбора входных данных (поток с камеры, карта/положение/цель, данные GPS), использование датасетов (`AgriVision-KZ`, `UAV-VisDrone`, `FlightLog`) и интерактивная демонстрация 5 классов методов ИИ (ML, CNN–LSTM, Decision Tree/Random Forest/XGBoost, Fuzzy Logic Мамдани, гибрид CNN–LSTM + EKF).
2. **[Этап 1: Подготовка данных и ПО](stage1.html)** — Симулятор OpenCV-обработки изображений (Gaussian Blur, CLAHE, Canny), удаление шума из GPS-сигнала, нормализация (Min-Max, Z-Score) и коррекция ошибок датчиков.
3. **[Этап 2: Генерация траектории](stage2.html)** — Интерактивная спутниковая ГИС-карта (Leaflet.js, Казахстан: Шортанды / Илийский район), генерация круговой, восьмеричной и произвольной (ИИ) траекторий с расчетом обхода препятствий.
4. **[Этап 3: Управление полетом](stage3.html)** — Симуляция движения дрона в реальном времени, сравнение PID-регулятора и нейросетевого агента PPO (RL) при порывах ветра и маневрировании.
5. **[Этап 4: Обнаружение объектов](stage4.html)** — Имитация видеопотока с бортовой камеры, инференс YOLOv8 с настраиваемым порогом Confidence, определение ГИС-координат (WGS-84) объектов и препятствий.
6. **[Этап 5: Создание карты](stage5.html)** — Симулятор SLAM-картирования окружающей среды с переключением **2D / 3D** карты, отображением рельефа, объектов и дрона с траекторией.
7. **[Этап 6: Изменение координат](stage6.html)** — Интерактивный геодезический калькулятор и пакетное преобразование `WGS-84 → ECEF → ENU`, график повышения точности (GPS vs RTK vs RTK+EKF+SLAM).
8. **[Этап 7: Принятие решений, расчет NDVI и Результаты](stage7.html)** — Пошаговое выполнение программы по блок-схеме (Рисунок 2), интеллектуальное управление моментом съёмки на основе расчета `NDVI = (NIR - Red) / (NIR + Red)` и признаков фитостресса (Рисунок 3), а также итоговые результаты прогнозирования, обучения и завершенная карта миссии.

## Запуск локально

Откройте `index.html` в браузере или запустите локальный статический сервер:

```bash
python -m http.server 8000
```
